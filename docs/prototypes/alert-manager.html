Alert Manager — interaction prototype

Throwaway mock for wayfinder ticket #76. The decision is native ui.Panel (ADR-0007), so this DOM mirrors Panels: groups are nested vertical panels, each row a horizontal panel of child components. Try: drag the ⠿ handle to reorder, drop onto a group row to nest, click the chevron to collapse, click rows (Ctrl/Shift for multi) to select and reveal bulk actions. The panel on the right is the live tree + selection state.
