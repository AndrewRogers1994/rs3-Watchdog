# Watchdog

## Summary

Build alerts from triggers and actions. Open the manager with its key or the Toggle button.

## Description

Watchdog builds alerts. An alert is a graph of nodes. A trigger watches the game. An action does something you can see or hear. Wire a trigger to an action and the action runs when the trigger does.

Open the manager with its key. The default key is F8. Clear that key on the settings page if you want F8 for something else. The Toggle button on the Watchdog content panel opens the manager too.

On the alert list, New alert starts a blank alert or copies a preset. Open an alert to edit its graph. Double-click empty space to add a node. Drag between the pins to connect them. Enable the alert in the list. A new alert starts enabled.

While you are in a restricted area, Watchdog will not alert you about nearby spawns, game messages, or walking into or out of a spot you chose. Other alerts still work.

A sound pack is another plugin registering builtin sounds. The Sound Effect node lists those sounds while that plugin is loaded. You can still type a builtin sound id by number.

## Data Protection

Watchdog stores alert graphs, alert names, the manager key, and the on-screen positions of infoboxes and toasts in the client. If tracking permission is on, it also stores a tracking id so alerts can be kept per character. Nothing is sent off the machine.
